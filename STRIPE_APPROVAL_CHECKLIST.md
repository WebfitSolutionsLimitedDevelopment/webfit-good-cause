# Stripe approval checklist

- [ ] Share pre-launch URL with Stripe
- [ ] Confirm whether existing Webfit Solutions Limited account can host the activity
- [ ] Obtain explicit guidance on crowdfunding/fundraising eligibility
- [ ] Confirm whether Stripe Connect is required
- [ ] Confirm Connect account type and charge model
- [ ] Confirm platform and connected-account fees
- [ ] Confirm domestic and international card pricing
- [ ] Ask about community/nonprofit/custom pricing support
- [ ] Confirm overseas beneficiary and disaster-relief restrictions
- [ ] Confirm payout schedule and reserves
- [ ] Confirm dispute and chargeback treatment
- [ ] Confirm refund capabilities
- [ ] Confirm required website disclosures
- [ ] Implement onboarding and identity requirements exactly as approved
- [ ] Implement signed webhook validation
- [ ] Test in Stripe test mode
- [ ] Obtain written go-live confirmation where available
- [ ] Only then set PAYMENTS_ENABLED=true
